# Poor man's Boom 3D

Your Mac’s audio, on stage in a real concert hall.

## Install

Needs macOS 14.2 or later and [Homebrew](https://brew.sh). It builds on your
Mac, which takes a few minutes.

```sh
brew install ashtonyoon/tap/poom3d
poom3d
```

`poom3d` puts an icon in the menu bar. The first time, macOS asks to let it
record system audio: choose Allow. With AirPods, turn their Spatial Audio off
in Control Center, since Poom3D does that part itself.
